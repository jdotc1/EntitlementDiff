# Clear Tree Search

Clear Tree Search empties the query, found results, selected hit and progress. Existing cancellation and request generations reject late completion. Clear remains available while searching and is disabled when there is nothing to clear or another app operation prevents interaction.

Comparison selection, inputs, filters, sorting, report contents and clipboard remain unchanged. No source scan or additional async stage is introduced. Navigation, Open Selected Match and Copy Selected Result Details become unavailable until new results provide the required state.

Two focused development methods and native completed/partial clear, retained selection, unchanged clipboard and fresh-search acceptance passed. Accepted UTF-8 matching, traversal, navigation, parser and report evidence reused. No suite or accessibility work rerun.
