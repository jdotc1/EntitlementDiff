# Previous/Next Result Navigation

Find Tree Text retains a selected result by stable identity. Previous Result and Next Result walk already discovered hits without wrapping or initiating more search. Next selects the first result when none is selected. Selection survives continuation as new hits append. Row selection, highlighting and Result k of N found distinguish selection from search completeness. Open Selected Match reveals the exact captured side and original match range.

Query edits and search restart clear selection. Source and entitlement replacement create a new search session; request generations and current-comparison checks suppress stale results and stale opens. Navigation is disabled during work. The tree-search detail scrolls within its split pane so controls and results remain reachable.

Two focused development tests and native navigation, continuation, opening, query-reset and scrolling acceptance passed. Accepted UTF-8 matching, parser, report and focused-viewer evidence reused. No full suite or accessibility work rerun.
