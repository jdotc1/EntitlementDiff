# Tree Search Side Scope

Search in Both (default), Previous or Current. Scope is captured in the search cursor, and excluded roots are never traversed. Existing traversal and string scan budgets, depth and result caps, UTF-8 fidelity and typed paths remain unchanged.

Changing scope cancels and invalidates current work, clears results and result selection, retains the query and requires an explicit Search Tree action. Clear retains the chosen scope. Completion/progress messages and copied result details name the search scope. Full comparison and schema-1 exports are independent of scope.

Three focused development methods and native Current/Previous scope, query retention, stale-result invalidation, scoped copy and Clear acceptance passed. Accepted unchanged evidence reused; no suite or accessibility work rerun.
